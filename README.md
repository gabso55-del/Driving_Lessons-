# DrivingInstructor App 🚗

A comprehensive driving instructor management app with scheduling, student tracking, and payment management.

## Features
- 📅 Calendar scheduling
- 👥 Student management
- 💰 Payment tracking
- 📊 Reports and analytics
- ☁️ Google Sheets backup

## Tech Stack
- Vanilla JavaScript (ES6 Modules)
- CSS3 with modern features
- Google Apps Script backend
- PWA support
